# 06 · 收集与长线：图鉴 / 工坊 / 博览会 / 排行榜（第 5 轮）

> 依赖：01（鱼获来源）、04（钓具来源）、05（等级解锁）｜被依赖：08（排行榜数据）

## 1. 图鉴

### 1.1 分类
`🐟 鱼类` / `🧩 材料` / `🎣 钓具` / `🤝 钓友`，顶部显示「已收集: X / Y」与总完成度百分比。

### 1.2 收录规则
- 鱼类：结算时选「📖 放入图鉴」→ 写入 `codex.fish[id] = { firstAt, maxWeight, count }`，**该鱼不可出售**
- 材料/钓具：首次获得即自动收录
- 钓友：08 添加好友后收录
- 未收录显示灰色 `❓ ???`，收录后显示图片/名称/稀有度/描述/首次时间/最大重量

### 1.3 里程碑奖励
- 每达成一个里程碑（如某类收集 5/10/20、总完成度 25%/50%）生成 `codexRewards[key] = { diamond, claimed }`
- 有未领取奖励时图鉴按钮显示红点；领取后 `claimed = true` 并加钻石
- 示例文案：「📖 图鉴奖励可领取！钓具图鉴 +3💎」

## 2. 工坊

- 解锁：达到 Lv.10（可配置）后 `workshop.unlocked = true`
- 功能：把鱼加工为「🍣 制品」，**售价 = 生鱼价 × productPriceFactor(1.6)**
- 有加工队列与倒计时，工坊等级提升可增加并行工位（消耗金币升级）
- 未解锁时显示「🔒 工坊 Lv.10 解锁」+ 一句话说明用途

## 3. 博览会

- 每日刷新一组「指定鱼种组合」任务（如：提交 1 条稀有 + 2 条普通）
- 展示所需鱼种与当前持有进度（`expoSubmitted` 记录）
- 完成后可领取金币/钻石大奖（`claimExpoReward`）
- 刷新周期：`expoLastRefresh` 记录日期，跨日自动刷新

## 4. 排行榜

- 四个维度：`🎖️ 段位` / `📖 图鉴` / `🐟 总鱼数` / `🐋 最重鱼`
- 数据来源：`stats` + `codex` + 云端（08 提供）
- 未接入云端时展示本地数据 + 灰显提示「联网后查看全服排行」
- 段位规则（本地）：按 `totalFishCaught + codex完成度×50` 分段：新手 / 熟练 / 高手 / 大师 / 传奇

## 5. state 片段

```js
codex: { fish: { snakehead: { firstAt, maxWeight, count } }, materials:{}, equipment:{} },
codexRewards: { fish_snakehead: { diamond: 3, claimed: false } },
workshop: { unlocked: false, level: 0, facilities: [] },
expo: {}, expoSubmitted: {}, expoLastRefresh: '',
bag: { fish: {}, products: {} }
```

## 6. 配置

```js
codex: {
  fishMilestones: [5, 10, 20, 40],      // 收集数量里程碑（对四种分类都生效）
  percentMilestones: [0.25, 0.5, 0.75, 1],
  diamondPerMilestone: 3,
  firstDiamond: 3                       // 🆕 首次收录某物种的奖励钻石
},
workshop: {
  unlockLevel: 10, baseSlots: 1, processSeconds: 60,
  slotCost: 500, slotCostGrowth: 1.8    // 🆕 升级工位：slotCost × slotCostGrowth^当前等级
},
expo: {
  refreshHour: 0, baseRewardGold: 300, baseRewardDiamond: 5,
  tasks: [                              // 🆕 每日任务池（跨日随机抽一条；只抽该稀有度有鱼的题）
    { name: '新手展区', reqs: [{ rarity: 'common',   count: 3 }] },
    { name: '河鲜展区', reqs: [{ rarity: 'common',   count: 2 }, { rarity: 'uncommon', count: 1 }] },
    { name: '稀有展区', reqs: [{ rarity: 'rare',     count: 1 }, { rarity: 'common',   count: 2 }] },
    { name: '精品展区', reqs: [{ rarity: 'uncommon', count: 3 }] },
    { name: '传说展区', reqs: [{ rarity: 'epic',     count: 1 }] }
  ]
},
rank: {                                 // 🆕 排行榜本地段位门槛（分数 = totalFishCaught + 完成度×50）
  tiers: [{ name:'新手', min:0 }, { name:'熟练', min:50 }, { name:'高手', min:150 },
          { name:'大师', min:400 }, { name:'传奇', min:1000 }]
}
```

## 7. 界面结构

```
[图鉴面板] 分类页签 / 网格卡片 / 完成度 / 红点
[工坊面板] 工位卡片 / 加工队列 / 倒计时 / 升级按钮
[博览会]  今日任务卡 / 所需鱼种进度 / 领取按钮
[排行榜]  四个维度切换按钮 / 列表（名次、昵称、数值、本人高亮）
```

## 8. 失败与反馈

| 场景 | 表现 |
|---|---|
| 放入图鉴的鱼尝试出售 | 明确提示「该鱼已珍藏，不可出售」 |
| 奖励已领取 | 按钮变为「已领取」灰态 |
| 工坊未解锁 | 说明解锁条件 |
| 博览会材料不足 | 显示缺哪几种鱼 |
| 排行榜无数据 | 空态文案，不报错 |

## 9. 边界（不要做）
- 不做社交好友的战力/加成（08）
- 不做工坊产出的自动售卖
- 不修改钓鱼核心循环

## 10. 本模块验收（清单 E 区）
- [ ] 鱼放入图鉴后不可出售且有明确提示
- [ ] 首次获得物品触发图鉴奖励，领取后钻石到账且红点消失
- [ ] 工坊未解锁有清晰说明；解锁后能加工并产出制品
- [ ] 博览会跨日能刷新，完成可领奖
- [ ] 排行榜本地数据正确，无数据时有空态

## 11. 实现口径（🆕 v1 已落地）

### 11.1 图鉴（`systems/codex.js` + `ui/codex.js`）
- **入口**：顶栏 📖 图鉴按钮 → 中央浮层（900px 宽），四个页签 `🐟 鱼类 / 🧩 材料 / 🎣 钓具 / 🤝 钓友`，
  页签上直接显示 `已收录/总数`；顶部「已收集 X / Y」+ 完成度百分比 + 进度条 + 总完成度
- **收录**：
  - 鱼类：结算选「📖 放入图鉴」→ `codex.recordFish(id, weight)` 写 `{ firstAt, maxWeight, count }`
  - 材料 / 钓具：首次获得即自动收录（03 收获入包、04 合成产出、07 购买 三处调用 `recordMaterial/recordEquipment`）
  - 钓友：08 未接入 → 页签内显示「随社交系统（08）开放」
- **未收录**：灰显 `❓ ???`（`grayscale + opacity`），收录后显示图标/名称/星级/最大重量/收录日期
- **奖励**：首次收录某物种 → `codexRewards['fish_first_{id}'] = { diamond: codex.firstDiamond, claimed:false, label }`；
  数量里程碑（`fishMilestones`）× 四种分类 + 总完成度里程碑（`percentMilestones`）各生成一条奖励
  - 红点：顶栏 📖 按钮上的 `#codex-dot` 显示未领取数量（>9 显示 `9+`），全部领取后消失
  - 领取：列表按钮「领取 +N💎」→ 钻石到账（同时累加 `stats.totalDiamondEarned`）→ 按钮变灰「已领取」；
    另有「🎁 一键领取全部奖励」
- **排行榜**（图鉴面板内按钮）：四维度 `🎖️段位 / 📖图鉴 / 🐟总鱼数 / 🐋最重鱼`。
  🆕 08 已接入 → 该入口优先调用 `systems.social.getRank()`（模拟云端玩家 + 本人高亮 + 离线灰字提示）；
  社交模块缺失时自动退回本模块的本地榜。细节见 08 §11.6；
  段位阈值来自 `CONFIG.rank.tiers`（分数 = `totalFishCaught + 完成度×50`）

### 11.2 工坊（🏭 底部导航页签）
- 入口：底部导航 🏭 工坊；未解锁（`level < workshop.unlockLevel=10`）显示
  「🔒 工坊 Lv.10 解锁」+ 用途说明 + 「当前 Lv.N，还差 M 级」；达标时 `checkWorkshopUnlock()` 自动解锁并 toast
- 🆕 **技能影响（05 经营系）**：`工位数 = baseSlots + workshop.level + round(「批量生产」加成)`、
  `加工秒数 = processSeconds × (1 - 「高效加工」加成)`（实测满级 60s → 51s）；未学技能时与旧版一致
- 界面：工位卡片（`baseSlots + workshop.level` 个）→ 空工位虚线卡 / 加工中卡片（进度条 + 剩余秒数 + 制品售价）/
  完成后绿色卡 + 「收取」按钮；下方「选择鱼投料」列表（每条鱼显示持有数、最重一条、预计制品售价）；
  再下方「制品（可出售）」列表带「出售」按钮；右上「⬆️ 升级工位 🪙N」
- 数值：`startProcess` 扣 1 条鱼（从 `bag.fish[id].weights` 取一条）、
  `unitPrice = getFishPrice(id, weight) × productPriceFactor(1.6)`、`endsAt = now + processSeconds×1000`
- 收取：`collectProcess(i)` 完成后才可收（未完成 → 提示「还在加工中（剩余 Ns）」），
  制品写入 `bag.products[id] = { count, unitPrice }` 并清空工位
- 升级：`slotCost × slotCostGrowth^level`，金币不足提示差额
- 倒计时：1s `setInterval` 刷新，**离开页签自动 `clearInterval`**（10 §9）

### 11.3 博览会（🏪 市场 → 🏆 博览会页签）
- 每日任务从 `CONFIG.expo.tasks` 随机抽一条；**只抽「当前鱼表里真有该稀有度」的任务**，避免不可完成
- 跨日刷新：`expoLastRefresh` 存 `YYYY-MM-DD`，日期变化 → 换题 + 清空 `expoSubmitted`
- 进展：每条要求显示 `已交 X / 需 N`、缺口标红；「上交 ×1」从 `bag.fish` 扣一条该稀有度的鱼
  （**已入图鉴的鱼不参与上交**，与不可售规则一致）
- 领奖：全部交齐才可点「🎁 领取奖励」→ `+baseRewardGold🪙 +baseRewardDiamond💎` + 100 经验（05 `awardExpo`），
  当日仅一次（`expo.claimed`）；未集齐 → 提示「还差 稀有×1、普通×2」
