# 00 · 总纲与投喂指南（每次投喂都必须带上本文件）

> 游戏名：🎣 疯狂钓鱼佬
> 定位：二合 + 休闲垂钓 + 轻模拟经营的**中度网页游戏**。
> 形态：**PC 浏览器桌面网页版**——全屏自适应布局，设计基准 1440×900，最小支持宽度 1024px。
> **不做手机竖屏版**；所有模块按桌面三栏布局实现。
> 本目录共 12 份文档：**本文件是唯一总纲**，其余每份描述一个模块。

---

## 1. 平台与布局规范

### 1.1 平台
- 形态：**PC 浏览器网页游戏**（单页应用；后续可迁移引擎，但首版不要引入任何引擎）
- 视口：**桌面优先**。设计基准 **1920×1080**；内容容器最大宽度 **1920px 居中**，最小宽度 **1536px**
  （🆕 宽度按实现反馈放大到 1.5×：1280 → 1920、1024 → 1536，用来承载写实钓场插画）
  - 窗口宽度 < 1536px 时整体等比缩放（`#app` 用 `transform:scale(innerWidth/1536)`），**禁止出现横向滚动条**
  - 高度适配 720~1080，主舞台自适应，侧栏内部滚动
- 语言：简体中文，emoji 作为主要图标体系
- 首屏加载 ≤ 3 秒，无外部字体依赖

### 1.2 桌面布局规范（所有模块统一，务必遵守）

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│ 顶栏   🎣 疯狂钓鱼佬 │ Lv.3 🪙253 ⭐358 💎0 │ 📖 🎒 ⚙️                            │
├────────────────────┬──────────────────────────────────────────┬────────────────┤
│ 左侧栏 260px        │ 主舞台（宽度自适应）                       │ 右侧栏 300px    │

│ 二合：合成台操作     │ 二合：36 格网格                           │ 钓场列表(7)（05）│
│ 合成：配方分类       │ 合成：配方卡（2 列）                       │ 装备槽 / 加成   │
│                    │ 技能：技能树（3 列分支）                    │ 盛产 / 最近收获  │
├────────────────────┴──────────────────────────────────────────┴────────────────┤
│ 底部导航：🧩二合 🎣钓鱼 🔨合成 🏭工坊 🏪市场 🌟技能 💎钻石 🌐社交                    │
└──────────────────────────────────────────────────────────────────────────────────┘
★ = 只在钓鱼页显示
```

> 🆕 **布局变更记录**（按实现反馈）：
> 1. 容器宽度 **1280 → 1920（1.5×）**，最小宽 **1024 → 1536**，窗口更窄时整体等比缩放；
> 2. 装备入口统一为**右栏「装备槽」**（左栏宫格已移除）；
> 3. **背包材料**不常驻页面，改由顶栏 🎒 浮层查看（四页签）；
> 4. **v4 定稿**：**等级卡片 + 钓场列表放右栏最上方，且只在钓鱼页显示**；
>    钓鱼页**左栏整列隐藏**（主舞台更宽），左栏只在二合/合成页出现（合成台操作 / 配方分类）；
>    技能页右栏显示「已学技能」汇总。
>    （历史：钓场曾放左栏 → 短暂移右栏 → v3 回左栏 → v4 定稿右栏最上方）
> 场景区使用 1080×603 写实插画（`background-size:cover` 居中贴底），场景高度随主舞台自适应。

- **主舞台是视觉重心**：场景区高度 ≥ 420px，主操作按钮居中且 ≥ 56px
- 侧栏卡片超出高度时内部滚动，不撑破页面
- 弹窗/面板统一为**中央浮层 + 半透明遮罩**，宽 480~640px，遮罩可点击关闭
- 所有可点元素必须有 **hover 态**（提亮 + 阴影 + `cursor:pointer`）
- 键盘快捷键（全局）：`空格` = 主操作（抛竿/拉），`Esc` = 关闭面板，`Enter` = 确认
- 连点区域加 `user-select: none`，避免选中文字

## 4. 全局架构规则（违反即返工）

1. **数值集中**：所有概率、时长、速度、消耗写在 `src/config.js`，业务代码禁止出现魔法数字。
2. **状态与渲染分离**：`state` 是唯一数据源；`render(state)` 只读不写；**禁止把状态存在 DOM 上**。
3. **状态机必有超时与出口**：任何"等待玩家"的阶段必须有超时分支 + 可放弃入口，禁止无限等待。
4. **模块边界**：每个模块独立文件，只通过 `state` 与公开函数通信，禁止跨模块直接操作 DOM。
5. **布局统一**：所有界面放进「顶栏 + 左栏 + 主舞台 + 右栏 + 底部导航」骨架，禁止各模块自造容器尺寸。
6. 🆕 **切页签必须整页刷新**：`switchTab()` 只能调 `FG.render.renderAll()`，**禁止只调 `renderStage()`**。
   顶栏数值/图鉴红点、右栏（装备槽数量、装备加成、盛产、最近收获）、等级卡/钓场卡都在 `renderAll` 链路里，
   只刷主舞台会让它们停留在上一次的值（真实 bug：合成饲料后回钓鱼页，饵料数量不更新）。

## 5. 技术约束

- 原生 JavaScript（ES Modules），**禁止 React/Vue 等框架**，**首版不使用 canvas**（DOM + CSS 渲染）
- 事件统一 `pointerdown`，**禁止 mousedown 与 touchstart 双绑**（会触发两次）
- 结构：
```
index.html
/assets/fish|item|scene/
/src/config.js  /src/state.js  /src/render.js
/src/systems/{fishing,equip,merge,craft,growth,codex,market,social}.js
/src/ui/{layout,toast,modal}.js
```
- 无构建也能跑；若用 Vite，保证 `index.html` 可直接打开
- 场景用 CSS 渐变 + emoji 装饰，鱼类用写实 PNG（`assets/fish/{id}.png`）

## 7. 视觉风格

**3D 卡通渲染风（Stylized 3D / Pixar 风格）**——手办玩具质感、柔和全局光照、浅景深背景虚化、低饱和柔和配色：

| 用途 | 色值 |
|---|---|
| 水面青绿 | `#7BC4B8` |
| 天空蓝 | `#9FD8E8` |
| 暖木色（卡片/按钮/边框） | `#C89B6A` |
| 标题深蓝 | `#1F3A5F` |
| 强调橙（收益/主按钮） | `#F5A623` |

- 圆角 16px；卡片带 1px 描边 + 轻投影；标题用深蓝粗体
- emoji 作为主图标体系；**主操作按钮 ≥ 56px，普通按钮 ≥ 40px**，间距 ≥ 8px
- 卡片带 `glow-{rarity}` 描边光效；hover 时提亮 + 轻投影
- 场景用 **3D 渲染背景图**（`assets/scene/{location}.png`），**每个钓场 1 张、16:9**，
  六个节点的状态差异靠叠加元素（浮标 / ❗气泡 / 水花 / 鱼）表现，**禁止每个节点切一张图**
- 场景图**已含垂钓角色**（统一形象：草帽 + 蓝马甲 + 米色衬衫 + 绿短裤 + 棕靴，坐姿持竿）
- 鱼类用**写实插画**（`assets/fish/{id}.png`）
- **不用 canvas**（DOM + CSS + SVG 动画即可）
- 所有图片缺失时必须用 CSS 渐变 / emoji 兜底，**禁止 404 报错**
