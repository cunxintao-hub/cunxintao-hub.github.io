# 08 · 社交系统（第 6 轮，可最后接入）

> 依赖：09（云同步与账号）｜被依赖：06（排行榜数据）
> **本模块依赖后端，若未接入云端请先实现"本地模拟版"，保证离线可玩。**

## 1. 账号与注册
- 昵称 2~8 字，唯一校验；生成 `#XXXXXX` 形式的短 ID 便于查找
- `socialProfile = { displayName, id, registered }`
- 未注册时所有社交功能显示引导注册卡；注册后数据云端同步

## 2. 钓友
- `🔍 查找钓友`：按昵称或 ID 搜索
- `🤝 钓友团`：好友列表 + 加成（每人 +5% 经验，上限 5 人）
- 添加好友后写入 `codex.friends`（06 收录）

## 3. 鱼王挑战
- 选择背包中的一条鱼向其他玩家发起挑战
- 判定：**金币价值高者获胜**
- 奖励：胜利 `+50🪙`
- 限制：`challengeToday = { date, sent, received }`，**每日限 3 次**，跨日重置
- 挑战记录可查看（收件箱 `📬 查看挑战`）

## 4. 世界频道
- 全局聊天，需内容过滤（敏感词替换 `*`）与发言间隔限制（≥3s）
- 未联网时显示「离线状态，联网后可查看世界频道」
- 刷新按钮手动拉取，不做长连接轮询

## 5. 排行榜
- 四个维度：🎖️ 段位 / 📖 图鉴 / 🐟 总鱼数 / 🐋 最重鱼
- 云端数据 + 本人高亮；无数据时展示本地榜 + 灰显提示

## 6. state 片段

```js
friends: [], friendLevels: {},
socialProfile: { displayName, id, registered },
challengeToday: { date, sent, received }
```

## 7. 配置

```js
social: {
  nameMin: 2, nameMax: 8,
  friendBonusPerFriend: 0.05, friendBonusCap: 0.25,
  challengeDailyLimit: 3, challengeWinReward: 50,
  chatMinIntervalMs: 3000, chatMaxLength: 60,
  /* 🆕 无后端 → 本地模拟云端（离线/超时/异常都降级为本地可用） */
  requestDelayMs: 600,          // 模拟往返耗时
  requestTimeoutMs: 8000,       // 请求超时（10 §2）
  inboxPerPull: 1,              // 每次刷新收件箱最多拉取条数
  nameCharset: /^[\u4e00-\u9fa5A-Za-z0-9_]+$/,
  bannedWords: ['外挂','作弊','骗子','代充','私服','广告'],   // 命中替换为 *
  chatSeed: [ /* 世界频道初始消息 3 条 */ ],
  npcPool: [ /* 8 位模拟云端玩家：{ id, name, level, fish, codex, biggest, bestFishValue } */ ]
}
```
> `challengeDailyLimit / challengeWinReward` 与 07 的 `economy.challengeDailyLimit / challengeWinReward` 同源，读取时以后者为准（07 §4）。

## 8. 失败与反馈

| 场景 | 表现 |
|---|---|
| 昵称重复/非法 | 输入框下方红字提示原因 |
| 未注册使用社交 | 弹出注册引导卡 |
| 挑战次数用尽 | 按钮禁用 + 「今日挑战已用完（3/3）」 |
| 背包无鱼 | 「背包里没有鱼，先去钓鱼吧」 |
| 断网 | 全部社交功能降级为本地版 + 统一提示，不影响核心玩法 |
| 发言过快 | toast「发言间隔 3 秒」 |

## 9. 边界（不要做）
- 不做实时对战、不做公会/组队
- 不做充值与排行榜奖励发放（06 负责）
- 不阻塞核心玩法：**任何云端异常都必须降级为本地可用**

## 11. 实现口径（🆕 v1 已落地，**无后端 → 本地模拟云端**）

> 入口：底部导航 🌐 社交；二合页快捷栏「🤝 钓友」也直达本页。
> 主舞台为「社交」页签，左侧仍是等级/钓场，右侧无额外卡片（保持三栏骨架）。

### 11.1 云端降级层（本模块最重要的一条）
- `social.request(label, cloud, fallback)`：所有"云端"调用统一走它
  - 离线（`navigator.onLine === false` 或玩家手动模拟断网）→ 立即返回 `fallback`，`offline: true`
  - 模拟往返 `requestDelayMs`；超过 `requestTimeoutMs(8s)` → 降级（10 §2 网络超时）
  - 云端逻辑抛异常 → 捕获 + 降级，**绝不向上抛**，不阻断任何玩法
  - 降级时统一 toast「🌐 当前离线/网络超时/云端异常，社交已切换本地模式（不影响钓鱼）」（同一分钟只提示一次，避免刷屏）
- 页面顶部状态条：🟢 已连接 / 🔴 离线模式 + 说明 + 「🌐 模拟断网 / 恢复联网」按钮（便于验收与自测）
- 离线时：查找钓友 / 收件箱 / 排行榜全部走 `CONFIG.social.npcPool` 本地数据；世界频道显示
  「离线状态，联网后可查看世界频道（不影响钓鱼）」；**钓鱼与其它核心玩法完全不受影响**

### 11.2 账号与注册
- 未注册 → 所有社交区块显示「需要注册」引导卡；注册卡为输入框 + 「注册」按钮 + **输入框下方红字**
- 校验顺序：空 → 长度 2~8（含当前字数）→ 字符集 `nameCharset`（中文/字母/数字/下划线）→ 唯一性（与 `npcPool` 重名视为被占用）
- 通过后 `socialProfile = { displayName, id: '#XXXXXX', registered: true }`（6 位，去掉易混淆的 I/O/0/1）

### 11.3 钓友与加成
- 查找：`searchPlayers(keyword)` 支持昵称或 `#ID`（大小写不敏感），留空列出全部；结果标「已添加」
- 添加：写 `state.friends[]`、`friendLevels[id]`、**`codex.friends[id]`（06 图鉴收录）**；重复添加 / 超上限都有文案
- 加成：`getFriendBonus() = min(friendBonusCap, friendBonusPerFriend × 好友数)`；上限 5 人 = 25%，
  面板显示进度条 + 「经验 +10%（2/5 位钓友）」
- **可观测**：`growth.addExp()` 里以 `1 + 技能expGain + 社交好友加成` 结算（唯一改动点，社交模块缺失时按 0 处理），
  实测 2 位好友时 100 经验 → 110 经验

### 11.4 鱼王挑战
- 出战鱼：`challengeFish()` 取背包里的鱼（同一鱼种取最重的一条），按 `market.getFishPrice` 算金币价值
- 判定：**金币价值高者胜**（对手价值取 `npcPool[].bestFishValue`）；胜 → `+challengeWinReward(50)🪙` + 飘字
- 次数：`challengeToday = { date, sent, received }`，`challengeDailyLimit = 3`；**同步先占位再发请求**，
  连点 6 次也只成交 3 次（剩余 3 次提示「今日挑战已用完（3/3）」）；日期变化自动重置
- 失败出口：未注册 / 背包无鱼 / 对手不存在 / 额度用尽，均有文案
- 📬 收件箱：每次挑战记录入 `state.social.inbox`（最多 20 条）；「📬 查看挑战（刷新）」拉取他人挑战（`received` +1）

### 11.5 世界频道
- 消息列表 + 输入框 + 「发送」+「🔄 刷新」（**手动拉取，不做长连接轮询**）
- 发言校验：需注册 → 非空 → ≤ `chatMaxLength(60)` → 间隔 ≥ `chatMinIntervalMs(3000)`（按钮显示「冷却 Ns」并禁用）
- 内容过滤：`bannedWords` 命中即替换为等长 `*`（发送前过滤，展示即已过滤）
- 频道记录存 `state.social.chat`（最多 50 条）

### 11.6 排行榜（四维度）
- 维度：🎖️ 段位（`totalFishCaught + 完成度×50`）/ 📖 图鉴完成度 / 🐟 总鱼数 / 🐋 最重鱼
- 数据 = 模拟云端玩家 + 本人；**本人行高亮**（`me` 标记）；离线时用本地榜并显示灰字
  「离线：当前为本地榜，联网后可查看全服排行」；无数据时给空态文案
- 06 图鉴面板里的「🏆 排行榜」入口优先走社交榜（社交模块缺失时自动退回本地榜）

### 11.7 state 与配置补充
- 🆕 `state.social = { inbox: [], chat: [], lastChatAt: 0, offlineSimulated: false, lastOfflineToast: 0 }`
  （懒初始化，随存档持久化）
- 🆕 `CONFIG.social` 新增：`requestDelayMs / requestTimeoutMs / inboxPerPull / nameCharset / bannedWords /
  chatSeed / npcPool[]`（模拟云端玩家：`{ id, name, level, fish, codex, biggest, bestFishValue }`）
- 数值全部集中在 config.js（00 §4.1），社交模块内无魔法数字
