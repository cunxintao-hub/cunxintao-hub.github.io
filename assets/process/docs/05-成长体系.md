# 05 · 成长体系：等级 / 钓场 / 技能树（第 4 轮）

> 依赖：01（提供经验来源）、02（装备）｜被依赖：06（图鉴/工坊按等级解锁）

## 1. 模块职责
等级与经验、7 个钓场的解锁与切换、技能树的学习与生效。

## 2. 等级与经验

- 升级所需经验：`expBase × expGrowth^(level-1)`
- 经验来源：
  | 行为 | 经验 |
  |---|---|
  | 成功钓上鱼 | `10 × 稀有度系数`（common 1 / uncommon 2 / rare 4 / epic 8 / legendary 15） |
  | 首次收录图鉴 | 30 |
  | 首次合成物品 | 15 |
  | 完成博览会 | 100 |
- 升级表现：全屏庆祝动画 + toast「🎉 升级！Lv.N」+ 列出本次解锁内容（钓场/配方/链）

### 2.1 实现口径（🆕 已落地）
- **唯一入口** `growth.addExp(amount, reason)`：先按「勤学苦练」加成换算实际经验，再判定升级；
  01/04 不再直接写 `state.exp`（钓鱼结算与首次合成改为调用 `growth.addExp` / `awardCraft`）
- 经验来源函数：`awardFish(rarity)`（10×稀有度系数）、`awardCodex()` 30、`awardCraft()` 15、`awardExpo()` 100
- **可连升多级**：`while (exp >= expToNext(level))` 扣减并 `level++`（带 200 次兜底防死循环）
- 等级卡片（🆕 放**右栏最上方**，只在钓鱼页显示）：`Lv.N` 药丸 + `⭐ 当前/所需` + 经验进度条 + 「还差 X 经验升级到 Lv.N+1」
- **升级弹窗**：列出本次区间内新解锁的 钓场 / 配方 / 合成链，每条 `data-tab` 可点击**直达对应页签**；
  没有解锁内容时给「继续攒经验」文案
- `expToLevel(target)`：逐级累加剩余需求，用于未解锁钓场提示「🔒 需要 Lv.N（还差 X 经验）」

### 3.1 实现口径（🆕 已落地部分）
- **位置（🆕 v4 定稿）**：等级卡片 + 钓场列表放**右栏最上方**（300px），且**只在钓鱼页显示**；
  钓鱼页左栏整列隐藏（主舞台更宽），左栏只在二合/合成页出现（合成台操作 / 配方分类）。
  7 个钓场**全部展示**（不是只显示已解锁的），统计条显示 `N/7 已解锁`
  - 已解锁：正常卡片，`✓` 药丸；当前钓场橙色描边 + `当前` 药丸
  - 未解锁：灰显 + `🔒` 药丸 + 右侧「预览」按钮，点击**只开预览浮层**，绝不切换钓场
- 🆕 **每行左侧用该钓场的场景插画做缩略图**（`scene.image`，没配图回退 emoji）
- 🆕 **点「预览」→ 场景视图浮层**（`openScenePreview`）：把该钓场的 1080×603 插画按 **16:9 完整呈现**
  （不裁切，保证浮漂落点百分比精确），并在画中浮漂位置叠**红白浮标 + 涟漪动画**（对齐 `scene.bobberAt`），
  左上角挂「🎣 场景预览 · 不可作钓」角标；下方列出解锁等级 / 鱼种数 / 状态 / 盛产鱼类（未收录 `❓ ???`）；
  未解锁时给出「🔒 需要 Lv.N 解锁，暂不能在此钓鱼」+ 「📋 查看解锁条件」按钮（切到信息弹窗）；
  已解锁时按钮变「📍 前往该钓场」（直接切换）
- 🆕 **点行本体仍是原行为**：未解锁 → 信息弹窗（解锁条件 + 鱼种）、已解锁 → 切换钓场；
  信息弹窗里也放了「🎬 查看场景」按钮，两个浮层互相可达
- **配置**：`CONFIG.locations[id] = { name, emoji, unlockLevel, desc, fish[], rarityWeight, scene }`，
  id 顺序即等级顺序；`unlockLevel` 达标才写入 `state.unlockedLocations`（只增不减，活动解锁也走这张表）
- **预览浮层**（可预览不可钓鱼）：图标 + 名称 + 解锁等级 + 氛围描述 + 鱼种列表
  （图鉴已收录显示名称/图标，未收录显示 `❓ ???`）+ 底部明确「🔒 需要 Lv.N 解锁，暂不能在此钓鱼」
- **兜底**：`currentLocation` 指向未解锁钓场时，抛竿被拦截并提示「尚未解锁，先在右栏切换钓场」；
  读档体检会剔除不存在的钓场 id 并把 `currentLocation` 拉回已解锁列表首项
- **场景图**：🆕 **7 个钓场各有一张 1080×603 写实插画**
  （`assets/scene/{river,stream,lake,river_big,offshore,deepsea,mystic}.png`），
  每场在 `scene.bobberAt` 标注画中浮漂/钓线入水点的图片内百分比，CSS 浮标与涟漪据此对齐
  （图片自带角色 → 不再叠 Lottie 人物动画层）；容器宽度 1.5×（1920 / 最小 1536）以承载横向插画

## 4. 技能树

- 消耗金币学习，**永久生效**，不可重置（或提供付费重置，首版不做）
- **六条线**（每线 3 个技能，同线内按顺序解锁；成本逐级 ×1.6）：

| 线 | 技能 | 效果（每级 → 满级） | 成本 |
|---|---|---|---|
| 手感 | 稳如泰山 | 绿区宽度 +5% | 200 |
| 手感 | 慢条斯理 | 指针速度 -10% | 350 |
| 手感 | 眼疾手快 | 咬钩窗口 +500ms | 500 |
| 收益 | 精打细算 | 售鱼价 +10% | 300 |
| 收益 | 勤学苦练 | 经验 +15% | 400 |
| 收益 | 体力充沛 | 体力上限 +2 | 600 |
| 概率 | 好运连连 | 稀有鱼概率 +3% | 800 |
| 概率 | 巨物猎人 | 鱼重量 +10% | 1000 |
| ⛏️ 采集系 | 矿工之眼 | 挖掘暴击率 0% → 10%（暴击时本次产出 ×2） | 500 |
| ⛏️ 采集系 | 自然亲和 | 采集稀有材料概率 0% → 5%（产出升级为同链 Lv.2） | 500 |
| ⛏️ 采集系 | 仓库扩容 | 合成台格位 0 → 10（36 → 46 格） | 1000 |
| 🎣 钓技系 | 精准抛竿 | 抛投距离 0% → 15%（换算为咬钩率提升） | 500 |
| 🎣 钓技系 | 铁腕遛鱼 | 命中区域（绿区）宽度 0% → 5% | 1000 |
| 🎣 钓技系 | 疯狂点击 | 收杆所需点击减少 0% → 10%（每次点击增益 +10%） | 1000 |
| 💰 经营系 | 精明商人 | 制品售价提升 0% → 10% | 500 |
| 💰 经营系 | 高效加工 | 加工时间减少 0% → 15%（60s → 51s） | 1000 |
| 💰 经营系 | 批量生产 | 同时加工数量 +1/级（工位 +1/+2/+3） | 2000 |

- 技能效果必须写入 `state.skills`，由各模块通过 `getSkillEffect(key)` 读取，**禁止硬编码进判定逻辑**
- 前置依赖：同一条线内需按顺序解锁；金币不足时按钮禁用并显示差额

### 4.1 实现口径（🆕 已落地）
- **配置**：`CONFIG.skills = { maxLevel: 3, costGrowth: 1.6, lines: [...] }`，
  技能 = `{ id, name, desc, cost, effect: { 效果 key: 每级数值 } }`；等级累加、成本 `cost × 1.6^当前等级`
- **读取**：`getSkillEffect(key)` 是唯一入口，返回已学技能的效果合计；`getSkillBonus()` 给面板汇总用
- **生效链路（都在 config 系数之上叠加，不动状态机）**：
  | 技能 | key | 生效位置 |
  |---|---|---|
  | 稳如泰山 | `targetWidth` | `growth.tuneDerived()` → 01 的绿区宽度 |
  | 慢条斯理 | `cursorSpeed` | 同上 → 01 的指针速度（张力阶段缓存到 `rt.tension.cursorSpeed`）|
  | 眼疾手快 | `biteWindow` | 同上 → 01 的咬钩窗口 |
  | 精打细算 | `fishPrice` | 01 掉落算价（07 市场复用）|
  | 勤学苦练 | `expGain` | `growth.addExp()` 内部换算 |
  | 体力充沛 | `chargeMax` | `merge.maxCharges()` → 挖掘/采集上限 |
  | 好运连连 | `rareRate` | 01 `rollFish()` 抬高高稀有度权重 |
  | 巨物猎人 | `fishWeight` | 01 `rollFish()` 重量倍率 |
  | 🆕 矿工之眼 | `digCrit` | `merge.produce('dig')` 判定暴击 → 本次产出 ×2 |
  | 🆕 自然亲和 | `rareMaterial` | `merge.produce('gather')` 判定 → 产出升级为同链 Lv.2 |
  | 🆕 仓库扩容 | `boardSlots` | `merge.boardSize()` = `gridSize + round(加成)` → 合成台 36→46 格（UI 网格与统计条同步） |
  | 🆕 精准抛竿 | `castDistance` | `growth.tuneDerived()` → 咬钩率 ×(1+15%) |
  | 🆕 铁腕遛鱼 | `targetWidth` | 同「稳如泰山」，两条线可叠加（绿区宽度取合计） |
  | 🆕 疯狂点击 | `reelGain` | `tuneDerived()` → `reelGainPerClick ×(1+10%)`（所需点击更少） |
  | 🆕 精明商人 | `productPrice` | `market.getProductPrice()` 制品售价 ×(1+10%) |
  | 🆕 高效加工 | `processSpeed` | `codex.workshopState().processSeconds ×(1-15%)` |
  | 🆕 批量生产 | `processSlots` | `codex.workshopState().slots + round(加成)` |
- `growth.tuneDerived(equip.getDerived())` 是 01 读派生数值的统一入口（02 的装备加成 + 05 的技能加成）
- 界面：主舞台分支卡片（**6 条线自动换行，每行 3 条**），节点四态 = 可学（橙色按钮带价格）/ 已学（高亮）/ 满级（绿色）/ 前置未学（灰显 +「需先学习 XX」）/ 金币不足（按钮禁用 + 还差多少）；
  节点同时显示「满级效果」（`desc`）与「每级效果」（`effectText`，计数型效果用格/个而非百分比）
- 右栏「已学技能」汇总同步展示全部效果 key（含新三条线：挖掘暴击率 / 采集稀有材料 / 合成台格位 / 抛投距离 / 收杆增益 / 制品售价 / 加工时间 / 工位数量）
- 🆕 **英雄加成走同一个入口**：💎 钻石系统招募的英雄（07 §10）与技能共用效果 key，
  `getSkillEffect(key)` 内部把两者相加 → 各模块既有接线点无需改动即可吃到英雄加成；
  「龙王使者」的 `allAttr +15%` 只放大**英雄**部分（技能不受影响）
- 存档：`state.skills` 持久化；读档体检会剔除未知技能 id 并把等级夹在 `0~maxLevel`

## 7. 失败与反馈

| 场景 | 表现 |
|---|---|
| 点击未解锁钓场 | toast「需要 Lv.N 解锁」+ 显示还差多少经验 |
| 金币不足学技能 | 按钮禁用 + 显示差额 |
| 前置技能未学 | 节点灰显 + 「需先学习 XX」 |
| 升级时 | 弹出解锁清单，可点击直达对应模块 |

## 8. 边界（不要做）
- 不做钓场的独立数值玩法（如天气/潮汐，后续版本再说）
- 不做技能重置
- 不修改钓鱼核心循环状态机（只通过配置与 effect 函数影响数值）
