## 调参指引

| 症状 | 先调这里 |
|---|---|
| 判定太难，总打不中 | `cursorSpeed` 降到 0.07；或 `targetWidthMin/Max` 提到 0.30/0.40 |
| 钓鱼太慢、等待无聊 | `waitMin/waitMax` 降到 1500/3500 |
| 一条鱼太容易/太难 | `requiredHitsRatio`（0.6 更宽松）、`roundsMin/Max` |
| 收杆点得手酸 | `reelGainPerClick` 提到 5；或 `reelDuration` 降到 4000 |
| 金币通胀 | `fishBasePrice` 降到 10~15 |
| 材料产出不足 | `charges.digMax/gatherMax` 提高、`regenIntervalMs` 降低 |
