# 12 · 验收清单（每轮结束逐条自检并汇报）

> 使用方法：本轮结束后，让 AI 对照**对应区域**逐条打勾并说明是否满足；不满足的必须修复后再进入下一轮。

## A 区 · 核心循环（第 1 轮）
- [ ] 四阶段状态机走通：抛竿 → 咬钩 → 张力 → 收杆 → 结算
- [ ] 成功路径可达：能完整钓上一条鱼
- [ ] 四条失败路径均可达且文案明确：咬钩超时 / 张力未达标 / 收杆超时 / 无鱼
- [ ] **张力阶段不操作会在 10 秒后自动失败**（不会永久卡住）
- [ ] 未装备鱼竿/饵料抛竿有提示且直达装备面板
- [ ] 指针速度与绿区宽度改 config 后立刻生效
- [ ] 定时器在阶段切换时被清理，不会状态串台
- [ ] 结算后金币/经验/统计正确累加

## B 区 · 装备与存档（第 2 轮）
- [ ] 点击装备槽弹出选择面板并能成功装备
- [ ] 每次抛竿消耗 1 个饵料，耗尽自动卸下且有提示
- [ ] 装备加成可观测（换鱼线 → 咬钩窗口变长）
- [ ] 刷新页面后等级、金币、背包、装备、网格全部保留
- [ ] 手动改坏存档后启动不白屏，能回退默认档
- [ ] 断网时保存/读取正常
- [ ] 设置面板保存/读取/重置生效且有二次确认

## C 区 · 合成（第 3 轮）
- [ ] 拖拽两个同名同等级材料能合成，材料数正确扣减
- [ ] 不同名/不同级拖拽回弹且有提示，状态不损坏
- [ ] 体力耗尽后按钮禁用并显示倒计时，到点恢复
- [ ] 网格满时产出有提示，不出现格子溢出
- [ ] 配方合成扣减数量与配方一致，材料不足时按钮禁用并显示缺什么
- [ ] 连点合成不会重复扣材料
- [ ] 首次合成触发图鉴奖励红点
- [ ] 合成产物能在装备面板中被选中

## D 区 · 成长（第 4 轮）
- [ ] 经验达阈值能升级，有提示与解锁清单
- [ ] 未解锁钓场不可进入且有「需要 Lv.N」提示
- [ ] 学习技能后金币扣除且效果可观测
- [ ] 刷新后等级、经验、技能、当前钓场保留
- [ ] 切换钓场后掉落与预览随之刷新

## E 区 · 收集与经济（第 5 轮）
- [ ] 鱼放入图鉴后不可出售，且不在售卖列表中
- [ ] 图鉴奖励可领取，领取后钻石到账、红点消失
- [ ] 工坊未解锁有说明；解锁后能加工产出制品
- [ ] 博览会跨日刷新，完成可领奖
- [ ] 售鱼价格符合公式，金币正确增加且鱼被移除
- [ ] 购买扣款正确，库存减 1，售罄显示补货倒计时
- [ ] 连点购买/出售不会重复扣款
- [ ] 所有资产变动都有 toast 与飘字

## F 区 · 社交（第 6 轮）
- [ ] 断网时游戏仍可钓鱼，社交页显示离线提示
- [ ] 挑战每日 3 次，跨日重置
- [ ] 好友加成生效且可观测
- [ ] 排行榜有本人高亮，无数据时有空态

## G 区 · 全局（每轮都要过）
- [ ] 桌面 1440×900 布局正常；窗口缩到 1024px 不出现横向滚动条
- [ ] 所有可点元素有 hover 态与 cursor:pointer
- [ ] 键盘快捷键（空格 / Esc）生效，且不与其他输入冲突
- [ ] 主操作按钮 ≥56px，普通按钮 ≥40px
- [ ] 任意弹窗都能关闭，不存在"点了没反应"
- [ ] 界面上无 `undefined` / `NaN` / `{占位符}` 残留
- [ ] 🆕 **切换页签后右栏/顶栏/等级卡同步刷新**（合成或购买装备后回钓鱼页，装备槽数量必须已更新）
- [ ] 连续快速点击不会导致重复扣资产
- [ ] 非法参数/异常状态不会导致整页空白
- [ ] 控制台无未捕获错误
- [ ] 高频动画用 rAF，无内存泄漏（切换阶段后定时器被清理）
