# 01 · 核心循环：钓鱼（第 1 轮，最高优先级）

> 这是整个游戏唯一必须一次做对的模块。**本轮只做这个，其他系统一律不实现。**

## 1. 模块职责
把"抛竿 → 咬钩 → 张力判定 → 疯狂收杆 → 结算"做到手感可玩，并覆盖全部失败路径与六个节点的视觉反馈。

## 2. 状态机（严格按此实现）

```
idle ──(点击抛竿, 校验通过)──> waiting
waiting ──(随机 waitMin~waitMax)──> biting
biting  ──(biteWindow 内点击场景)──> tension
biting  ──(超时)──> fail('反应太慢，鱼跑了...') ──> idle
tension ──(命中数达标)──> reel
tension ──(未达标 / tensionTimeout 超时 / 玩家放弃)──> fail('鱼挣脱了...') ──> idle
reel    ──(reelDuration 内进度达 100%)──> caught
reel    ──(超时)──> fail('收杆失败') ──> idle
caught  ──(三选一结算)──> idle
```

**硬约束：从 `tension` 进入后，无论玩家是否操作，最长 `tensionTimeout` 毫秒内必须离开该状态。**

> 注意：张力判定与疯狂收杆是**两个独立阶段**（判定考时机、收杆考手速），不要合并。

## 4. 本模块配置（写进 config.js 的 `CONFIG.fishing`）

```js
fishing: {
  waitMin: 2500, waitMax: 6000,      // 抛竿到咬钩的等待(ms)
  biteWindow: 4000,                  // 咬钩响应窗口(ms)【基准 3000，实装 +1s 降难度】
  biteBaseRate: 0.9,                 // 基础咬钩概率（受饵料吸引加成，见 02）
  roundsMin: 3, roundsMax: 4,        // 张力判定轮次
  requiredHitsRatio: 0.6,            // 需要命中比例（向上取整）【基准 0.75，实装 0.6：4 轮需 3 次、3 轮需 2 次】
  cursorSpeed: 0.105,                // 指针速度 %/ms（≈105%/s，跑完单程约 950ms）
  targetWidthMin: 0.20, targetWidthMax: 0.28, // 安全区宽度占条比
  reelDuration: 6000,                // 收杆时长(ms)【基准 5000，实装 +1s 降难度】
  reelGainPerClick: 5.7,             // 每次点击进度增益 %【基准 3.5，实装 5.7：×力量 1.1 = 6.27%/次 → 16 次满进度】
  tensionTimeout: 10000              // 张力阶段超时(ms)
}
```

> **手感微调记录**：玩家反馈整体偏难，实装值相对文档基准做了如下放宽：
>
> | 参数 | 文档基准 | 实装 | 效果 |
> |---|---|---|---|
> | `biteWindow` | 3000 | **4000** | 咬钩反应窗口 +1s |
> | `reelDuration` | 5000 | **6000** | 收杆时长 +1s |
> | `reelGainPerClick` | 3.5 | **5.7** | 每次点击 +6.27%（含力量加成），**所需点击 26 → 16 次** |
> | `requiredHitsRatio` | 0.75 | **0.6** | **4 轮只需命中 3 次**（3 轮需 2 次） |
> | `tensionTimeout` | 10000 | 10000 | 未改动（本就宽松） |
>
> 还嫌难：继续加 `reelGainPerClick`（每 +1 ≈ 少 2 次点击）或降 `requiredHitsRatio`；
> 嫌判定太难还可调 `cursorSpeed`（指针速度）与 `targetWidthMin/Max`（绿区宽度）。

## 5. 各阶段细节

### 阶段一 · 抛竿等待
- 点击「🎣 抛竿！」→ 播放**甩竿动画**（钓竿旋转 + 虚线抛物线 + 落水涟漪扩散）→ 进入等待
- 等待期：浮标轻微上下浮动（2s 循环）+ 水面细微波纹；提示「🎣 抛竿中...等待鱼儿上钩」
- **前置校验（强制）**：
  - 未装备鱼竿 → toast「未装备鱼竿」+ 自动打开装备面板（02 提供 `openEquipPanel('rod')`），**中断抛竿**
  - 未装备饵料 → 同上，类型 `bait`
- 校验通过后按 `biteBaseRate` 判定是否真的会咬钩；不咬钩则在等待结束后直接 `fail('这片水域暂时没有鱼...')` 回 idle

### 阶段二 · 咬钩
- 场景内浮标上方弹出 **❗ 气泡**（缩放弹出动画）+ 水面剧烈水花粒子
- 气泡下方保留文字兜底：「❗ 有鱼咬钩了！快点击！」
- 玩家点击**场景任意位置**即提竿成功
- `biteWindow` 内未点击 → `fail('😢 反应太慢，鱼跑了...')`，**不计消耗**

### 阶段三 · 张力判定（手感核心）
- **竖直张力条**（放在场景右侧，高度 ≥ 320px、宽 40~56px），自下而上渐变：**红（危险）→ 黄（临界）→ 绿（安全）**
- 条上有 **白色指针**，从 0% 到 100% **往复移动**，速度 `cursorSpeed %/ms`，用 `requestAnimationFrame` 驱动，逐帧更新位置
- 安全区（绿段内的高亮区间）每轮随机位置与宽度（`width ∈ [targetWidthMin, targetWidthMax]`，且不越界）
- 玩家点「🎯 拉！」→ 判定指针是否落在安全区内
  - 命中：`✅ 命中！` + 绿色闪烁；未命中：`❌ 未命中` + 红色抖动
  - 判定后立即进入下一轮（安全区重新随机）
- 轮数 `rounds` 随机 3 或 4；需要命中数 = `ceil(rounds × requiredHitsRatio)`
- 判定结束：达标 → `reel`；未达标 → `fail('😢 拉力失败，鱼挣脱了...')` 并显示命中明细
- **必须有 10s 超时自动失败** + 剩余时间提示 + 「放弃」按钮

### 阶段四 · 疯狂收杆
- 显示「🔥 疯狂收杆！」+ 进度百分比 + 剩余倒计时
- 主按钮「🎣 拉！拉！拉！」旁显示 **旋转手势图标**（持续旋转，提示连续点击）
- 每次点击 → 进度 `+reelGainPerClick%`，数字跳动 + 按钮缩放动画
- 5s 内达 100% → `caught`；超时 → `fail('😢 收杆失败')` 并显示最终进度
- 达 100% 瞬间播放**鱼出水动画**（鱼形上移 + 水花飞溅）

### 阶段五 · 鱼获结算
中央浮层卡片（木牌/羊皮纸质感，圆角 16px，宽 480px）：

- 顶部标题「🎉 恭喜获得！」
- 中部：鱼的写实图（无图时 emoji 占位）+ 名称 + **稀有度星级（★×N）**
- 下方：重量（2 位小数 kg）+ 一句话描述 + **金币数字（+153 🪙，跳动动画）**
- 三个操作按钮：

| 操作 | 行为 |
|---|---|
| 🎒 收入背包 | 进 `bag.fish`，可后续在市场出售（07） |
| 📖 放入图鉴 | 写 `codex`，**不可出售**；首次收录触发钻石奖励红点（06） |
| 🪙 立即售卖 | 立即结算金币 = `fishBasePrice × rarityFactor × weight`（见 11） |

结算后统一：加经验、加金币、更新 `stats`（总鱼数 +1、最重鱼取 max、总收益累加）、触发存档、回 idle。

**🆕 结算卡片必须"停留到做出选择"**（v2 修正）：
- 进入 `caught` 后先播 `catchShowMs`(1.4s) 的「4.上了」演出，再弹卡片（避免居中卡片立刻盖住视频）
- 卡片用 `dismissible:false` 打开：**没有 ✕、点遮罩不关、Esc 不关**，只能点三个按钮之一才继续
  （原因：收杆阶段是连点操作，遮罩可关的话连点尾巴会误关卡片 → 自动 `settle('bag')` → 鱼还没看清就进下一次）
- 卡片出现后 `catchClickGuardMs`(250ms) 内忽略按钮点击，防止连点顺手误选（例如本想放图鉴却点了立即售卖）
- 只要没人选，阶段就停在 `caught`，绝不会被点没

### 7.1 🆕 阶段背景视频（只做演出，不改交互）

> 一段 `<video>`（静音 + `playsinline`，铺满场景 `object-fit:cover`，z-index 0 在所有叠加层之下），
> 按钓鱼阶段切换片源；**状态机、按钮、判定、结算逻辑完全不变**，视频只是把静态背景换成动态演出。

| 阶段 | 视频 | 播放方式 |
|---|---|---|
| `idle` 未开始 | `assets/video/idle.mp4`（0.等待） | 循环 |
| `waiting` 抛竿 | `assets/video/cast.mp4`（1.钓鱼） | **只播一次**，播完/超时（`castVideoMaxMs` 2.6s）自动接 `wait` |
| `biting` 等待咬钩 | `assets/video/wait.mp4`（2.等待） | 循环 |
| `tension` / `reel` 拉线收杆 | `assets/video/fight.mp4`（鱼咬钩拉扯·12.26s 长镜头） | **原速循环，不强行播完**：搏斗多久播多久；鱼一钓上来（`caught`）或跑掉（失败演出）立刻切下一条 |
| `caught` 成功上鱼 | `assets/video/success.mp4`（4.上了） | **先播 `catchShowMs`(1.4s) 演出再弹结算卡片**（卡片是居中浮层，立刻弹会盖住视频）；卡片用浅色遮罩 `modal-light`，视频继续在背后循环 |
| 失败（没鱼/咬钩超时/张力未达标/收杆超时） | `assets/video/fail.mp4`（4.断了） | 演出 `resultVideoMs`(2.8s) 后自动回到当前阶段视频 |

**实现口径**：
- 配置在 `CONFIG.fishing.videos`（`{ src, seconds, once }`），映射集中在 `render.phaseVideoKey()`，**业务模块不感知视频**
- **时长拉伸**：`playbackRate = 视频时长 ÷ seconds`（`seconds>0` 时），并夹在 `videoRateRange [0.35, 1.6]` 内；
  `seconds=0` 表示按原速循环（等待类视频）
- **🆕 结果即切**：拉扯视频（`reel`）用 `seconds:0` 原速循环，搏斗多久播多久；
  一旦进入 `caught` 或触发失败演出，`applySceneVideo / flashSceneVideo` **立刻换源**播下一条，不等拉扯视频播完
- **兜底**：视频缺失/解码失败 → `error` 事件里移除 `video-on` 类，场景自动回退到 `assets/scene/{location}.png`
  插画 / CSS 渐变，**不报 404、不白屏**（10 §5）；自动播放被浏览器拦截时静默失败，仍走兜底
- **不占后台资源**：切换离开钓鱼页 → `pauseSceneVideo()` 暂停并隐藏（同时取消未播完的结果演出）
- 有视频时不显示 Lottie 人物层（`.video-on .scene-actor{display:none}`），避免与视频里的垂钓者重影；
  CSS 浮标/涟漪仍保留（咬钩下沉等反馈是交互的一部分）
- 失败演出期间用 `flashUntil` 锁住阶段刷新，保证「断了」这一下播完不被立刻覆盖
- **结果演出要看得到**：上鱼后的「🎣 鱼获结算」浮层用**浅色遮罩**（`modal.open({light:true})` →
  `.modal-backdrop.modal-light` 0.18 透明度），让背后的 `success.mp4` 透出来；失败没有浮层，`fail.mp4` 直接可见。
  实测序列：抛竿 `cast.mp4` → 上鱼 `success.mp4`（结算卡显示鱼名/稀有度/星级/重量/价格）→ 结算后 `idle.mp4`；
  钓不到时 → `fail.mp4` 演出后回 `idle.mp4`

### 7.1 六个节点的视觉反馈（必须逐个实现）

| 节点 | 画面表现 | 实现方式 |
|---|---|---|
| ① 抛竿 | 甩竿 + 虚线抛物线 + 落水涟漪 | 钓竿 CSS 旋转 + 轨迹 SVG + 涟漪扩散 |
| ② 等待 | 浮标静止，水面细微波纹 | 浮标上下浮动（2s 循环） |
| ③ 咬钩 | ❗ 气泡弹出 + 剧烈水花 | 气泡缩放弹出 + 水花粒子 |
| ④ 收线 | 竖直张力条 + 指针移动 + 旋转手势图标 | rAF 驱动指针；旋转图标提示连点 |
| ⑤ 捕获 | 鱼被拉出水面 + 水花飞溅 | 鱼形上移动画 + 粒子 |
| ⑥ 结算 | 「恭喜获得」卡片 + 星级 + 金币数字 | 中央浮层 |

**背景图每个钓场只有一张**：六个节点共用同一张场景插画，靠叠加元素区分状态，**禁止每个节点切一张图**。

## 8. 失败与反馈（强制，AI 常遗漏）

| 场景 | 必须表现 |
|---|---|
| 未装备鱼竿/饵料 | toast 文案 + 直达装备面板，不静默失败 |
| 咬钩超时 | 文案 + 立即可重抛 |
| 张力未达标 | 文案 + 命中/未命中明细 |
| 张力阶段无操作 | **10s 自动失败**（不得永久停留） |
| 收杆超时 | 文案 + 最终进度百分比 |
| 图片资源缺失 | emoji/CSS 兜底，控制台无 404 报错 |

## 9. 本模块边界（不要做）
- 不做装备切换逻辑（只调用 02 的 `openEquipPanel`）
- 不做材料/合成/市场/图鉴（图鉴只调用 06 的 `collectToCodex`）
- 做**必要的阶段反馈动效**（见 7.1 六节点表）；除此之外的装饰性特效一律不做
