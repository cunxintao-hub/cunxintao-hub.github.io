# 10 · 交互与异常规则（全局约束，每轮投喂必带）

> 这一章专治"AI 只写成功路径"。**以下每条都是强制项，不是建议。**

## 1. 操作反馈（任何点击都必须有响应）
- 按钮：`pointerdown` 即缩放 0.96 + 变色，禁止"点了没反应"
- 资产变动：必须 toast（如「💰 售出 黑鱼 获得 153 金币」「✨ 合成了 🫠 松脂！」）
- 长耗时操作：显示 loading 态，禁止界面假死

## 2. 超时兜底（每个等待玩家的阶段）
| 阶段 | 超时 | 表现 |
|---|---|---|
| 咬钩响应 | 3s | 文案失败 + 可重抛 |
| 张力判定 | 10s | 自动失败 + 显示命中明细 |
| 疯狂收杆 | 5s | 自动结算 + 显示最终进度 |
| 网络请求 | 8s | toast「网络超时」+ 保留本地数据可继续玩 |

**禁止出现任何"不操作就永久停留"的状态。**

## 3. 弹窗与遮罩
- 🆕 **遮罩有两种浓度**：默认深色（`rgba(38,49,92,.45)`，面板类通用）；
  需要露出背景演出时用浅色 —— `modal.open({ light: true })` → `.modal-backdrop.modal-light`（`rgba(16,32,52,.18)`），
  目前用于「🎣 鱼获结算」（让背后的 `success.mp4` 演出可见）
- 遮罩默认可点击关闭，任意位置点击都能退出（除非是有损操作需二次确认）
- 🆕 **例外：必须做出选择才能继续的浮层**用 `modal.open({ dismissible: false })`：
  隐藏 ✕、遮罩点击与 `Esc` 都不关闭，**只能点面板里的按钮**；
  目前用于「🎣 鱼获结算」（收杆是连点操作，若遮罩可关，连点的尾巴会点到遮罩把卡片"点没"，
  玩家没选就自动进背包）。同时这类浮层出现后的 `catchClickGuardMs`(250ms) 内忽略按钮点击（防连点误选）
- 🆕 键盘：`Esc` 只在 `modal.isDismissible()` 为真时关闭浮层，不得绕过强制选择
- 引导类弹窗**不得阻断主流程超过 1 次点击**；同一引导只弹一次（localStorage 记录）
- 弹窗出现时不得吞掉后续点击事件（关闭后需清理 backdrop 的 display/pointer-events）

## 4. 防重复提交
- 涉及资产的操作（合成、购买、售卖、挑战、领取奖励）必须：
  - 节流 ≥ 300ms
  - 加结果锁（上一次未返回时不接受新请求）
  - 成功后立即禁用/变更按钮态，防止连点重复扣材料

## 5. 非法状态与参数
- 状态切换函数对入参做**白名单校验**：非法值 → 回退默认状态 + `console.warn`，**禁止出现全部面板隐藏的空白页**
- 例如 `switchTab(key)` 必须校验 key 在合法列表内，非法则回退 `'fishing'`
- 渲染前对缺省数据给默认值，禁止 `undefined` / `NaN` 出现在界面上

## 6. 桌面端（PC 浏览器）
- 布局：容器最大宽 1280px 居中，最小宽 1024px；窗口更小时整体等比缩放，**禁止出现横向滚动条**
- 高度：适配 720~1080；主舞台自适应，侧栏内部滚动
- 鼠标：所有可点元素必须有 **hover 态**（提亮 / 阴影 / `cursor:pointer`），禁止"看不出能不能点"
- 键盘：`空格` = 主操作（抛竿 / 拉），`Esc` = 关闭当前面板，`Enter` = 确认；快捷键不得与输入框冲突
- 事件统一 `pointerdown`，**禁止 mousedown 与 touchstart 双绑**
- 主操作按钮 ≥ 56px，普通按钮 ≥ 40px，间距 ≥ 8px
- 高频连点区域加 `user-select: none`，避免连点时选中文字
- 弹窗统一中央浮层（480~640px），遮罩可点击关闭

## 7. 文案规则
- 全部简体中文，emoji 作图标
- 禁止占位符残留（`{name}`、`undefined`、`null`、`NaN`）
- 数字格式化：重量 2 位小数，金币/经验整数，超 10000 显示「1.2万」

## 8. 数据一致性
- 任何"扣减 + 增加"必须成对且在同一事务内完成，中途失败要回滚
- 扣减前先校验充足性，不足时禁用按钮并提示缺什么（不出现负数）

## 9. 性能
- 高频动画用 `requestAnimationFrame`，禁止 `setInterval` 做逐帧动画
- 列表渲染超过 50 项做分页/懒加载
- 定时器在离开阶段时必须 `clearTimeout` / `clearInterval`（防止状态串台）

## 10. 可观测性（便于排查）
- 每个模块关键节点 `console.log('[模块] 事件', 关键参数)`
- 全局暴露 `window.__state` 指向 state，便于调试
- 捕获 `window.onerror`，出错时 toast「出现异常，已恢复到安全状态」并回 idle
