# 03 · 材料与二合合成（第 3 轮）

> 依赖：00（体力与网格写入 state）｜被依赖：04（配方合成消耗材料）
>
> **v2 修订**：按实现反馈调整了材料产出与链条解锁规则，并参考同源线上实现（`ai-native-*.tcloudbaseapp.com` 的《疯狂钓鱼佬》）补齐了链数与统计条口径。改动集中在 §2 / §4 / §5，新增 §6 自动生成；下方带 🆕 标记。

## 1. 模块职责
36 格材料网格、拖拽二合升级、材料产出（自动生成/挖掘/采集/一键收获/购买）与体力系统。

## 2. 玩法定义
- 网格 **6×6 = 36 格**（🆕 05「仓库扩容」技能满级 **+10 → 46 格**，`merge.boardSize()` 动态计算，
  统计条与网格一起变；旧档格子索引仍有效），格子状态：空 / 占用（物品 + 等级）
- **合成规则**：拖拽 A 到 B
  - 两者「同名且同等级」→ 合并为**高一级**物品，A 清空、B 升级，`mergeCount +1`
  - 目标格为空 → 移动（清空来源格）
  - 不同名 / 不同级 → **回弹**（来源格抖动）+ toast「只能合并相同物品」，状态不变
  - 已达链条最高级 → toast「已达最高等级」
- 降级交互：不支持拖拽时，支持「点击 A 再点击 B」完成同样操作；`Esc` 取消选中
- 🆕 **链条共 8 条**（泥土/植物/矿石/锻造/涂料/食材/宝石/织物），每条 4 级
- 🆕 **基础材料必须都能合成**：默认 8 条链全部解锁（`progressiveUnlock: false`）；
  若切换为 `true`（对齐参考实现的「链: 2/8」成长曲线），则按合成次数逐条解锁

## 3. state 片段

```js
mergeGrid: [ { id, level, cell: 0..35 }, ... ]   // 最多 36 项
mergeCount: 0                                     // 累计合成次数
digCharges: 8, gatherCharges: 8, lastChargeRegen: <timestamp>
bag.materials: { clay: { count: n, level: 1 }, ... }
// 自动生成的定时器属于运行时，不入档
```

## 4. 配置

```js
merge: {
  gridSize: 36,
  gridCols: 6,
  cellSize: 76,                     // 桌面格子 76×76
  maxLevel: 8,                      // 全局上限，实际以各链长度为准
  progressiveUnlock: false,         // false=全部解锁（默认）；true=按合成次数逐条解锁

  chains: {                         // 数组顺序即等级顺序（index+1 = Lv）
    soil:  { name: '泥土链', unlockLevel: 0, items: ['clay','resin','brick','ceramic'] },
    plant: { name: '植物链', unlockLevel: 0, items: ['hay','wood','hardwood','ebony'] },
    ore:   { name: '矿石链', unlockLevel: 0, items: ['ore','iron_bar','steel','alloy'] },
    forge: { name: '锻造链', unlockLevel: 0, items: ['scrap','nail','gear','spring'] },
    paint: { name: '涂料链', unlockLevel: 0, items: ['sap','glue','varnish','lacquer'] },
    food:  { name: '食材链', unlockLevel: 0, items: ['worm','corn','paste','bait_mix'] },
    gem:   { name: '宝石链', unlockLevel: 0, items: ['pebble','crystal','gem','diamond_shard'] },  // 🆕
    cloth: { name: '织物链', unlockLevel: 0, items: ['fiber','thread','cloth','brocade'] }         // 🆕
  },
  chainOrder: ['soil','plant','ore','forge','paint','food','gem','cloth'],
  chainUnlockAtMergeCount: [0,0,3,8,15,25,40,60],   // 仅 progressiveUnlock=true 时生效
  rarityByLevel: ['common','common','uncommon','rare','uncommon','rare','epic','legendary'],

  source: {                         // 🆕 挖掘/采集的候选基础材料（随机产出）
    dig:    ['ore','scrap','clay'],          // 可开采：铁矿石 / 废料 / 黏土
    gather: ['hay','sap','worm','wheat']     // 可采集：干草 / 树液 / 红虫 / 麦粒（🆕 麦粒是饵料主料）
  },
  producePerAction: 3,              // 🆕 单次挖掘/采集的产出数量
  harvest: { free: true, minLevel: 2 },  // 🆕 一键收获：只收 Lv.2+（二合过一次以上）的材料
  randomPlacement: true,            // 🆕 新材料从空位里随机选格落下（false=按格子顺序填空）

  autoSpawn: {                      // 🆕 合成台自动随机生成
    enabled: true,
    intervalMs: 10000,              // 每 10 秒产出 1 个
    levelWeights: [88, 9.5, 2, 0.5] // Lv1~Lv4 权重（%）：基础材料为主，小概率高级材料
  }
},
charges: {
  digMax: 8, gatherMax: 8, regenIntervalMs: 10*60*1000, regenAmount: 1,  // 🆕 10 分钟回 1 点
  buy: { enabled: true, buyAmount: 3, buyCost: 15, fullCost: 20 }        // 🆕 补充探索次数（金币）
}
```

## 5. 材料产出

| 入口 | 行为 |
|---|---|
| ⛏️ 挖掘 | 消耗 **1 点**挖掘体力，从 `source.dig` 三种基础材料里**随机产出 3 个**（种类逐个随机，可能混出）🆕 |
| 🌿 采集 | 消耗 **1 点**采集体力，从 `source.gather` 三种基础材料里**随机产出 3 个**🆕 |
| 📦 一键收获 | 🆕 **只收已合成过的材料（Lv.2 及以上）**（`harvest.minLevel=2`，格子右下角有 📦 金边角标）进背包 `bag.materials`；Lv.1 原始材料（没二合过）**还不能收**，要留在台上先合成一次。免费、不消耗体力、不产出新材料。没有够等级的材料时提示「暂无可收集的物品」 |
| 🔋 补充次数 | 🆕 打开「补充探索次数」面板，用**金币**快速补充挖掘/采集次数（`+3` 花 15 金币、`满充` 花 20 金币补到上限），不影响自然恢复计时 |
| 🛒 购买 | 跳 07 市场购买材料（放入网格或背包，视网格空位） |
| 🗑️ 清空 | 二次确认后清空网格（提示会丢失） |

- 体力为 0 时**挖掘/采集**按钮禁用并显示恢复倒计时（格式 `mm:ss`）；
  🆕 **一键收获不受体力限制**，只在**合成台为空**时禁用（它收的是台面上已有的材料）
- 🆕 **Lv.2 及以上才能收**（每条链 4 级）：
  Lv.1 原始材料 →（合成 1 次）→ **Lv.2 可收** →（合成 2 次）→ **Lv.3 可收** →（合成 3 次）→ **Lv.4 可收**
  判定用 `level >= harvest.minLevel`（默认 **2**），与"合成过几次"解耦，改配置即可调整门槛
- 🆕 **收获去向**：够等级的材料进入背包 `bag.materials`（累加数量），对应格子清空，**低等级材料不动**；
  04 配方合成与钓鱼消耗通过 `countOwned() = 合成台 + 背包` 取用，先扣合成台再扣背包
- 🆕 台面上没有够等级的材料时，点击收获明确提示
  「暂无可收集的物品——需要 Lv.2 以上的材料（先二合 1 次）」（次数按 `minLevel-1` 自动算）

### 6.x 🔋 补充探索次数（金币）
- 面板文案：`次数每 <恢复间隔>自动恢复 1 次，也可以用金币快速补充。`（间隔读 `charges.regenIntervalMs`）+ 当前金币
- 两行：`⛏️ 挖掘次数 当前 n/8` 与 `🌿 采集次数 当前 n/8`，各带 `+3 🪙15`、`满充 🪙20` 两个按钮
- 购买规则（每条都必须有出口，10 §2）：
  - 金币与次数**成对变更**，任一步失败整体回滚（10 §8）；资产操作走 `throttleLead`，连点不重复扣金币
  - 次数已满 → 拒绝并提示「已满，无需补充」，按钮置灰
  - 剩余不足 `buyAmount`（如只剩 1 次）→ 拒绝并提示「请直接用满充」，避免按整价多收（`+3` 按钮置灰）
  - 金币不足 → 拒绝并提示差额，按钮置灰
- 体力恢复：距 `lastChargeRegen` 每满 `regenIntervalMs` 恢复 `regenAmount`，上限 `digMax/gatherMax`；
  两管体力都满时重置计时，避免攒次数
- 网格已满时产出失败 → toast「合成台已满，请先合成或清空」（按剩余空位截断，不会溢出）

## 6. 🆕 合成台自动随机生成

- 每隔 `autoSpawn.intervalMs`（默认 **10000ms / 10 秒**）自动在空位里放入 **1 个**材料
  （36 格从空到满约 6 分钟，节奏以"玩家有空合并"为准）
- **落点随机**：从当前所有空位里随机选一格落下（`randomPlacement`），不是按格子顺序填空
- 材料来源：8 条链均匀随机 → 链内按 `levelWeights` 抽等级（88% Lv1、9.5% Lv2、2% Lv3、0.5% Lv4）
- 约束：
  - 网格满（36 格）→ 暂停生成，仅提示一次「合成台已满，自动生成已暂停」；合并/清空后自动恢复
  - 页面隐藏（切标签页）→ 该次跳过，不累积
  - 玩家正在拖拽时只更新数据、不重建格子 DOM，避免打断操作
- 该产出不消耗体力，属于"挂机产出"，与挖掘/采集并行

### 6.1 🆕 技能对产出的影响（05 采集系）
- **矿工之眼（`digCrit`，满级 10%）**：挖掘时按概率暴击 → **本次产出 ×2**，toast 追加「💥 矿工之眼暴击 ×2」
- **自然亲和（`rareMaterial`，满级 5%）**：采集时按概率把 1 个产出**升级为同链 Lv.2**（无链材料不升级），
  toast 追加「✨ 自然亲和 N 个稀有材料」
- **仓库扩容（`boardSlots`，满级 +10 格）**：合成台容量 36 → 46，网格与「空位: n/46」同步
- 三者都只读 `growth.getSkillEffect(key)`，未学技能时行为与旧版完全一致

> 🆕 **背包材料不再常驻左栏**（原先在钓鱼/二合/合成三页都挂一张「🧱 背包材料」卡，材料一多就把左栏撑爆）。
> 改为**只在背包浮层里看**：点顶栏 🎒（或合成台快捷栏「背包」）打开「🎒 背包」浮层，
> 四个页签 `🐟 鱼类 / 🧱 材料 / 🎣 钓具 / 📦 制品`，数据全部只读自 `state.bag`：
> - **材料卡**：左上角来源标签（`自然/加工/饵料`）+ 图标 + 中文名 + `×数量`；
>   标签规则 = `CONFIG.materialTag` 显式指定优先，其余按等级推导（Lv.1 自然、Lv.2+ 加工），
>   排序 `自然 → 加工 → 饵料`；顶部显示「N 种 · 合计 M 件」
> - **鱼类卡**：稀有度星级 + 图鉴未收录时标「未收录」
> - **钓具卡**：显示所属分类（鱼竿/鱼钩/…）与「已装备·{槽位}」标记（仍禁止在背包内装备，02 §5.1）
> - **制品页**：空态给出口「工坊 Lv.10 解锁后可加工（06）」
> - 页签切换原地换内容、不关弹窗；材料为空时给引导文案「去材料二合把材料合到 Lv.3 以上，再点 📦 一键收获」

**桌面布局**：网格放在**主舞台居中**，6 列 × 6 行，格子 **76×76px**（物品显示 emoji + 名称 + `Lv.N`）；
拖拽用 `pointerdown` 按住移动（位移 >8px 判定为拖拽），拖动中显示半透明跟随层与目标格高亮边框；

> 🆕 **拖拽手感实现口径（v2 修正「幽灵不跟手」）**：
> - 跟随层 `#merge-drag-layer` **挂到 `document.body`**：`#app` 在窗口窄于 1536 时带 `transform: scale()`，
>   内部 `position:fixed` 会以 `#app` 为包含块、坐标被缩放 → 幽灵与鼠标错位；
>   挂 body 后用**视口坐标**（`e.clientX/Y`）定位即精确跟手，再按 `appScale()` 给跟随层自身 `scale()` 补偿视觉大小
> - 移动时**只更新坐标**（物品没变就不重建 innerHTML），避免逐帧重建导致的闪烁
> - 被拖起的**源格子加 `.dragging`**（`opacity .35` + 灰度），落位后清除；有材料的格子 `cursor:grab`
> - 网格监听之外，**`document` 层再加一层 pointermove/pointerup 兜底**（指针捕获失效或鼠标移出网格也能继续跟随、正常收尾）
> - 松手落在网格外 → 材料原样留在原格、跟随层收起（不静默丢件）
左栏放统计与操作区，右栏显示当前悬停/选中物品的名称、等级、所属链与下一级产物。
窗口较窄（≈1024px）时网格在卡片内横向滚动，**页面级不出现横向滚动条**。

- 物品格显示：emoji + 名称 + `Lv.N`，按稀有度描边
- 拖拽中显示半透明跟随 + 目标格高亮
- 合成成功：toast「✨ 合成了 🫠 松脂！」+ 目标格缩放动画

## 8. 失败与反馈

| 场景 | 表现 |
|---|---|
| 拖到不同名/不同级 | 回弹 + toast「只能合并相同物品」 |
| 拖到已满级物品 | toast「已达最高等级」 |
| 体力不足 | 按钮禁用 + 显示恢复倒计时 |
| 网格已满（挖掘/采集） | toast「合成台已满，请先合成或清空」 |
| 网格已满（自动生成） | 暂停生成，仅提示一次「合成台已满，自动生成已暂停」🆕 |
| 链未解锁（仅 progressiveUnlock=true） | toast「🔒 该链需要 Lv.N 且合成 M 次后解锁」 |
| 连点挖掘/采集 | 前置节流 300ms，窗口内忽略，防重复扣体力 |

## 9. 边界（不要做）
- 不做配方合成（04）、不做材料上架售卖（07）
- 不改动钓鱼核心循环
- 首版不做自动合成（`autoMerge` 字段预留，默认 false）
