## 3. 配置

```js
craft: {
  categories: ['rod','hook','bait','line','net','other'],
  allowDuplicateCraft: true,     // 已拥有仍可再合成
  showOwnedCount: true,
  lockByLevel: true,             // 未达等级显示 🔒 需要 Lv.N
  firstCraftDiamond: 3,          // 首次合成写入图鉴奖励的钻石数（06 领取）
  recipes: [ /* 见 §2 的 26 条：6 鱼竿 + 5 鱼钩 + 5 鱼线 + 3 渔网 + 7 饵料 */ ]
}
```

## 4. 状态与流程

```
点击「🔨 合成」
  → 校验：等级解锁？材料充足？（二者都不过 → 按钮禁用 + 显示原因）
  → 扣减材料（一次性事务，失败回滚）
  → bag.equipment[id].count += 1
  → toast「🔨 合成成功！获得 🏑 木质鱼竿」
  → 若首次获得：codexRewards['equipment_' + id] = { diamond: 3, claimed: false }
     并 toast「📖 图鉴奖励可领取！」+ 图鉴红点（06 负责领取 UI）
  → 刷新列表（材料 拥有/需求 实时变化）
```

## 5. 界面结构

```
[分类页签] 🎋鱼竿 🪝鱼钩 🪱饵料 🧵鱼线 🥅渔网 📦其他   （每个页签显示「N 个配方 · 可合成 M」）
[配方卡片 .craft-item(.craftable)]
  🎣 竹制鱼竿  [普通]                          已拥有: 1
  🎍竹子 8/3   🪢绳索 5/1   🫗胶水 5/1        ← 不足时红色
  💪 力量:5 ｜ 📏 范围:1
  [🔨 合成]  或  [材料不足]（禁用） 或 🔒 需要 Lv.5
```

> 属性名按装备类型显示：鱼钩 `🎯钩率:60% ｜ 🛡️强度:3`、鱼线 `🛡️拉力:5 ｜ 🕶️隐蔽:20%`、
> 渔网 `✨加成:10%`、鱼竿 `💪力量:8 ｜ 🍀运气:2 ｜ 📏范围:2`（百分比属性自动补 `%`）。
> 分类顺序即页签顺序：`rod / hook / bait / line / net / other`。

- 材料文本格式：`{emoji}{名称} 拥有/需求`，不足时红色加粗
- 卡片按稀有度描边；已拥有的显示 `已拥有: N`
- 锁定配方灰显 + 锁图标 + 解锁等级文案
- **桌面布局**：配方卡在主舞台内以 **2 列网格**排列（而非单列），分类页签在左栏纵向排列；
  卡片 hover 提亮，右栏显示当前悬停配方的完整属性与材料缺口

## 6. 失败与反馈

| 场景 | 表现 |
|---|---|
| 材料不足 | 按钮禁用为「材料不足」+ 缺项标红 |
| 等级未到 | 卡片灰显 + 「🔒 需要 Lv.N」 |
| 合成连点 | 节流 300ms + 结果锁，禁止重复扣材料 |
| 材料中途不足 | 校验通过但扣减失败 → 回滚 + toast |

## 7. 边界（不要做）
- 不做材料产出（03）、不做装备切换（02 负责）
- 不自动装备产出物（只入背包，提示玩家去装备）
- ~~不做渔网配方（首版该分类为空态提示）~~ → 🆕 v2 已补齐 3 个渔网配方，
  `CONFIG.equip.lockedSlots` 清空、渔网槽位可装备（**加成的玩法落地待 06 工坊/渔网玩法接入**）
