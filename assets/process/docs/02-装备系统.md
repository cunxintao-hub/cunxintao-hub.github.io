# 02 · 装备系统（第 2 轮）

> 依赖：01（钓鱼会读取装备并调用本模块的装备面板）
> 被依赖：04（配方合成产出装备）、07（市场购买）

## 1. 模块职责
管理 5 个装备槽位、装备切换、饵料消耗与耗尽提示，并向 01 暴露只读属性查询接口。

## 2. 槽位与属性维度（🆕 v2 按参考稿对齐）

| 槽位 key | 名称 | 属性（参考稿叫法） | 作用 |
|---|---|---|---|
| `rod` | 🎋 鱼竿 | 💪 力量 power / 🍀 运气 luck / 📏 范围 range | 力量提升收杆进度增益；运气影响掉落品质；范围影响可钓距离 |
| `hook` | 🪝 鱼钩 | 🎯 **钩率** accuracy / 🛡️ **强度** tough | 钩率增大张力绿区宽度；强度延长咬钩响应窗口 |
| `line` | 🧵 鱼线 | 🛡️ **拉力** tough / 🕶️ **隐蔽** stealth | 拉力延长咬钩响应窗口；隐蔽小幅提升咬钩概率 |
| `bait` | 🪱 饵料 | 🧲 吸引 attract | 提升咬钩概率（**消耗品**，每次抛竿消耗 1 个） |
| `net` | 🥅 渔网 | ✨ **加成** bonus | 渔获加成（🆕 已可合成/装备，玩法落地待 06） |

- **同一属性在不同装备上的显示名不同**：`tough` 在鱼钩上叫「强度」、在鱼线上叫「拉力」；
  由 `ENUM.STAT_NAME_BY_TYPE` + `ENUM.statName(type, key)` 统一解析，UI 禁止硬编码属性名。
- 百分比属性（`钩率 / 隐蔽 / 加成`）在界面上自动补 `%`。
- 属性加成必须走统一函数 `getEquipStat(type)`，由 01 在计算时调用，**禁止硬编码**。

## 3. state 片段

```js
equipped: { rod: 'bamboo_rod', hook: 'bone_hook', bait: 'corn_bait', line: 'fiber_line', net: null }
bag.equipment: { bamboo_rod: { count: 1 }, corn_bait: { count: 5 } , ... }
```

## 4. 配置

```js
equip: {
  // 属性对玩法的换算系数（01 调用）；🆕 按参考稿的数值口径重新标定
  powerToReelGain: 0.02,        // 每点力量 +2% 收杆增益（力量 5~60）
  accuracyToTargetWidth: 0.002, // 每点钩率 +0.2% 绿区宽度（钩率 60~90 → +12%~18%）
  attractToBiteRate: 0.01,      // 每点吸引 +1% 咬钩概率（吸引 5~45）
  toughToBiteWindow: 40,        // 每点拉力/强度 +40ms 咬钩窗口（3~25）
  stealthToBiteRate: 0.004,     // 🆕 每点隐蔽 +0.4% 咬钩概率（隐蔽 20~70 → +8%~28%）
  baitConsumePerCast: 1,        // 每次抛竿消耗饵料数
  lowStockThreshold: 1,         // 低于该值触发"即将耗尽"提示
  lockedSlots: []               // 🆕 渔网启用后清空（原 ['net']）
}
```

> ⚠️ 标定说明：参考稿的「钩率」是百分比（60~90），而旧公式 `0.004` 是按「命中 3~11」设计的。
> 若沿用旧系数，骨制鱼钩会把绿区从 24% 撑到 38%，因此把系数下调到 `0.002`，保持手感与文档一致。

## 5. 交互流程

### 5.1 装备入口（唯一入口）
钓鱼页点击某个装备槽（如 `#equip-bait`）→ 弹出「选择{类型}」面板 → 列出背包中该类型全部物品（名称、稀有度、属性、持有数）→ 点击即装备 → 关闭面板 + toast「已装备 XX」。

**禁止在背包面板内装备**（背包只做查看与详情，见 06/07）；若保留点击，必须给出明确反馈，不能"点了没反应"。

### 5.2 饵料消耗
- 每次成功抛竿消耗 `baitConsumePerCast` 个饵料
- 剩余 ≤ `lowStockThreshold` → toast「⚠️ 饵料即将耗尽」
- 数量归零 → 自动卸下（`equipped.bait = null`）+ toast「饵料已用完，请装备或购买」+ 提供「去购买」按钮跳 07
- **未装备饵料时抛竿**：01 调用 `openEquipPanel('bait')`，并 toast「未装备饵料，无法钓鱼」

### 5.3 装备加成生效
01 在计算时读取：
```
reelGainPerClick = CONFIG.fishing.reelGainPerClick × (1 + power × powerToReelGain)
targetWidth      = base × (1 + accuracy × accuracyToTargetWidth)
biteRate         = CONFIG.fishing.biteBaseRate + attract × attractToBiteRate
biteWindow       = CONFIG.fishing.biteWindow + tough × toughToBiteWindow
```

## 7. 界面结构（🆕 装备槽统一放**右栏**，点击即开中央浮层）

> **改动记录**：原先左栏挂一张「🎣 装备选择」2×2 宫格卡，右键槽位卡与右栏「装备槽」功能重复，
> 且左栏占掉 260px。现已**移除左栏装备卡**（钓鱼页左栏整列隐藏，主舞台变宽），
> 装备入口统一为**右栏「🛠️ 装备槽」**列表 —— 两者本来就调用同一个 `openEquipPanel(slot)`，行为完全一致。

```
[右栏 · 装备槽]  🛠️ 装备槽                      02
  ▪️ 鱼竿  竹制鱼竿      💪力量 5  📏范围 1
  ▪️ 鱼钩  骨制鱼钩      🎯命中 3
  ▪️ 饵料  玉米饵        ×5
  ▪️ 鱼线  纤维鱼线      🛡️韧性 2
  ▪️ 渔网  未装备
[中央浮层 · 选择饵料] ✕
  🌽 玉米饵 [普通] 吸引:8 (x5)
  🔻 红虫饵 [优良] 吸引:15 (x5)
```

- 装备槽条目 hover 提亮，点击弹出选择面板（hover 高亮，点击即装备并关闭）
- 选择面板为中央浮层（宽 480px）
- 未装备槽位显示灰色「未装备」；已装备显示名称 + 稀有度描边；饵料额外显示剩余数量
- 5 个槽位（含未开放的渔网）在右栏一屏可见；钓场列表占右栏最上方，装备槽紧随其后

## 8. 失败与反馈

| 场景 | 表现 |
|---|---|
| 该类型背包为空 | 面板显示「暂无可用{类型}，去合成或购买」+ 跳转按钮 |
| 饵料耗尽 | toast + 自动卸下 + 购买入口 |
| 装备面板打开时点击遮罩 | 关闭面板（不得拦截主流程） |

## 9. 本模块边界（不要做）
- 不做合成（04 负责产出）、不做购买（07 负责）
- 不修改钓鱼核心循环的状态机
