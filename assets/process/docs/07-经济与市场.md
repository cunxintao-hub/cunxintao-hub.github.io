## 1. 双货币

| 货币 | 来源 | 消耗 |
|---|---|---|
| 🪙 金币 | 售鱼、售制品、博览会、鱼王挑战胜利 | 买材料、学技能（05）、工坊升级（06） |
| 💎 钻石 | 图鉴里程碑（06）、博览会、工坊产出 | 解锁图鉴位、加速、兑换金币 |

兑换：`diamondToGold = 100`（1💎 → 100🪙，单向）

## 2. 定价公式

```
生鱼售价 = fishBasePrice × rarityPriceFactor[rarity] × weight(kg)
制品售价 = 生鱼售价 × productPriceFactor
```
```
fishBasePrice: 30
rarityPriceFactor: { common:1, uncommon:2.2, rare:5, epic:12, legendary:30 }
productPriceFactor: 1.6
```
> 示例：黑鱼(rare) 5.11kg → 30 × 5 × 5.11 ≈ 767（可按体感下调，首版建议先用 30/5 试跑，或把 `fishBasePrice` 调到 6 使首鱼约 150 金币）

## 5. 结算与反馈（强制）
- 每次资产变动必须 toast：`💰 售出 黑鱼 获得 153 金币` / `🛒 购买 绳索 ×1，花费 8 金币`
- 顶部资源栏数字做滚动动画 + 变化飘字（+153 / -8）
- 出售成功后从 `bag.fish` 移除，同步更新 `stats.totalGoldEarned`

## 6. 失败与反馈

| 场景 | 表现 |
|---|---|
| 金币不足 | 购买按钮禁用 + 显示差额 |
| 库存售罄 | 显示「今日售罄」+ 补货倒计时 |
| 出售已入图鉴的鱼 | 明确提示不可售（该条目不出现在售卖列表） |
| 连点购买/出售 | 节流 300ms + 结果锁，禁止重复扣款 |
| 背包为空 | 空态文案「背包里没有鱼，去钓鱼吧！」 |

## 7. 边界（不要做）
- 不做真实支付与充值（钻石仅游戏内产出）
- 不做玩家间交易
- 不改钓鱼核心循环

## 9. 实现口径（🆕 v1 已落地）

### 9.1 定价（`systems/market.js`）
- `getFishPrice(id, weight) = fishBasePrice × rarityPriceFactor[rarity] × weight × (1 + 技能「精打细算」)`（四舍五入）
  - 技能加成只经 `growth.getSkillEffect('fishPrice')` 读取（05 §4 硬约束）
- `getProductPrice(id)`：优先用加工时存下的 `bag.products[id].unitPrice`；缺失时退回「生鱼中位重量价 × productPriceFactor」；
  🆕 两条都会再乘 `(1 + 技能「精明商人」)`（05 经营系，满级 +10%），技能效果实时生效、无需重新加工
- 示例核对：黑鱼(rare) 4.00kg → `30 × 5 × 4 = 600🪙`（面板「均价 / 合计」同步展示）

### 9.2 🏷️ 售卖页签
- 列表 = `market.sellableFish()`（**已入图鉴的鱼带 `collected` 标记并被过滤掉**，页面下方用一行灰字说明「另有 N 种鱼已入图鉴（珍藏中，不可出售）」）
- 每条显示 稀有度标签 / `×数量` / 均价 / 合计 + 「出售 ×1」；制品的单独一栏 + 「出售 ×1」
- 「💰 一键出售全部鱼」「🍣 一键出售全部制品」→ **二次确认浮层**（列出条数与预计收益）后才执行
- 出售：从 `bag.fish[id].weights` 依次取重（即按存入顺序）计价，全卖完则删除该条目；同步累加 `stats.totalGoldEarned`

### 9.3 🛒 购买页签
- 库存结构：`state.market = { stock: { rope: n, ... }, restockAt }`（首次访问懒初始化，随存档持久化）
- `refreshStock()`：`now >= restockAt` 时按 `marketStock` 补满，并把 `restockAt` 推后 `restockIntervalMs(24h)`
- 每行显示 剩余/上限、单价；售罄 → 按钮变「今日售罄」+ 顶部补货倒计时（`hh:mm:ss`，
  购买页签内 1s 刷新，**离开页签/切页签自动停表**）
- 购买：`扣金币 + 库存 -1 + bag.materials +1 + 图鉴收录` 成对完成，异常整体回滚；
  金币不足 → 按钮置灰 + 「金币不足（还差 🪙N）」；非售卖物品 → 直接拒绝（`console.warn`）
- 页底附钻兑金：`1💎 → diamondToGold(100)🪙`（单向）

### 9.4 资产反馈（强制项落地）
- 每次买卖/领奖 → `FG.toast(...)` + `ui/float.js` 飘字（`+600🪙` / `-8🪙` / `+3💎`，1.1s 上浮淡出，最多错开 3 行）
- 连点防护：所有资产按钮走 `utils.throttleLead`（窗口期内只执行第一次，不补尾调用）
- 状态字段：`state.market.{stock,restockAt}` 已补进 00 §8 state 总表

## 10. 🆕 💎 钻石系统（钻石商店 + 英雄招募）

> 入口：底部导航 **💎 钻石**（桌面横版一页，四个分区卡片；交互逻辑对齐参考实现，布局按横屏重排）。
> 实现：`systems/diamond.js` + `ui/diamond.js`；配置集中在 `CONFIG.diamond`。

### 10.1 页面结构（自上而下）
| 分区 | 内容 |
|---|---|
| 顶部余额 | 💎 当前钻石（大号）+ 获取途径 chips（解锁图鉴 / 完成博览会 / 工坊产出）+ 「1💎 = 100🪙（单向）」+ 已招募英雄 n/8 |
| 💰 金币兑换 | 三档横排：`1💎→100🪙`（少量补充）、`10💎→1000🪙`（中量）、`100💎→10000🪙`（大量）；右侧表头显示换算率 |
| 🧰 材料捆绑包 | 6 个礼包：红色「省 X%」角标 + 图标 + 名称 + 材料清单 + `💎 钻石价` + **原价 🪙 划掉** + 购买按钮；表头右侧「💎 更划算!」 |
| ⚙️ 自动合成 | 未开通：`🔒 达到 Lv.15 后可用 💎50 开通（当前 Lv.N）`；已开通：状态 + 「⏸ 暂停 / ▶️ 开启」 |
| 🦸 英雄招募 | 8 位英雄卡片：头像 + 名字 + 星级/稀有度（英文字段）+ 加成文案 + 解锁等级；未达标显示 `🔒 Lv.N`，达标显示 `💎N 招募`，已招募显示 `✅ 已招募`；顶部一行「当前加成」汇总 |

### 10.2 三个交互规则
1. **金币兑换**：复用 `market.exchangeDiamondToGold()`（单向，不可逆），钻石不足 → 按钮置灰 + 文案；连点由 `throttleLead` 拦截
2. **礼包折扣是算出来的**：`省 X% = 1 - 钻石价 × diamondToGold / 原价金币`，
   所以 `5💎(500🪙) vs 800🪙 → 省 38%`、`50💎(5000🪙) vs 15000🪙 → 省 67%`（与参考稿数值一致，改汇率/价格会自动同步）
3. **购买礼包**：扣钻石 → 材料进 `bag.materials` + **自动收录图鉴（06）**；扣钻与入包成对完成，异常整体回滚（10 §8）
4. **自动合成**：`Lv.15 + 50💎` 开通（开通即开启），之后每 `autoMerge.intervalMs(2s)` 自动在合成台上找一对「同名同等级且链已解锁」的材料合并（低等级优先，逻辑在 `merge.autoMergeStep()`）；
   页面可随时暂停；定时器在暂停/离开时 `clearInterval`，读档时若为「已开通 + 已开启」会自动恢复循环

### 10.3 英雄招募与永久加成
| 英雄 | 稀有度 | 解锁 | 招募价 | 效果 | 生效位置 |
|---|---|---|---|---|---|
| 🐣 老王 | common | Lv.5 | 10💎 | 经验 +10% | `growth.addExp()` |
| 👨‍🍳 李大厨 | common | Lv.8 | 12💎 | 售价 +15% | `market.getFishPrice()` |
| ⚒️ 张铁匠 | uncommon | Lv.12 | 25💎 | 制作速度 +20% | 工坊 `processSeconds`（60s → 48s） |
| 🧑‍🏫 孙先生 | uncommon | Lv.15 | 30💎 | 图鉴奖励 +25% | `codex.claimReward()` 钻石 ×1.25 |
| 🛳️ 赵船长 | rare | Lv.20 | 60💎 | 稀有鱼概率 +15% | 01 `rollFish()`（经 `rareRate`） |
| 🧪 吴炼师 | rare | Lv.25 | 70💎 | 材料翻倍概率 +10% | `merge.produce()` 产出再给一份 |
| 🏴‍☠️ 陈海盗 | epic | Lv.30 | 150💎 | 金币收益 +30% | 售鱼 / 制品 / 博览会 / 鱼王挑战奖金 |
| 🐲 龙王使者 | legendary | Lv.40 | 300💎 | 全属性 +15% | **放大其它英雄的加成**（技能不受影响） |

- **统一入口**：英雄加成与技能共用同一套效果 key，`growth.getSkillEffect(key)` 里把两者相加 →
  01/03/06/07 的所有既有接线点**无需改动**即可吃到英雄加成（03 只读 `getSkillEffect`）
- 招募校验顺序：非法 id → 已招募 → 等级不足（提示还差几级）→ 钻石不足（提示差额）
- 数值：`state.heroes = { id: true }`、`state.autoMergeOpened`；读档体检会剔除配置里不存在的英雄 id

### 10.4 钻石的产出与消耗（闭环）
- **产出**：图鉴里程碑/首次收录（3💎，孙先生 +25%）、完成博览会展区（10/15/20/30💎）、
  🆕 工坊收取制品按 `workshop.diamondChance(20%)` 掉 1💎
- **消耗**：兑换金币、买材料礼包、开通自动合成、招募英雄（全部走同一个 💎 余额，单向不可逆）
